# StreamCast — статус проекта

## Текущее состояние
Проект готов к публикации. Проведен полный аудит безопасности, исправлены уязвимости открытого редиректа и утечки данных в API.

### ✅ Реализовано
- **Безопасность**:
    - Принудительная смена дефолтного пароля при первом запуске (Setup-экран).
    - Защита от открытых редиректов в `/login`.
    - Корректная обработка `X-Real-IP` (только через прокси).
    - Устранение утечек `str(e)` в ответах API.
- **Стабильность**:
    - Добавлен `encoding="utf-8"` во все вызовы `subprocess` (исправлено для Windows).
    - Настройка хоста и порта через переменные окружения.
    - Автогенерация `STREAMCAST_SECRET`, если он не задан.
- **Инфраструктура**:
    - Лицензия MIT.
    - Очищен `requirements.txt` (gunicorn вынесен в опциональные).
    - Обновлен `.env.example`.

### 🛠️ Архитектура
- **Flask**: Основной API и веб-интерфейс.
- **Encoder**: Фоновое перекодирование видео в единый стандарт (1080p/30fps).
- **Streamer**: Управление ffmpeg-процессами, бесконечный цикл трансляции, hot-reload очереди.
- **Storage**: SQLite для метаданных + локальные папки для медиа.
