# Карта проєкту StreamCast

Проєкт: Self-hosted панель для цілодобових (24/7) трансляцій на YouTube (RTMP).
Шлях: `/root/projects/cloned_repos/StreamCast`

## Структура
- `README.md`, `README.en.md`, `STATUS.md` — документація.
- `app.py` — веб-панель.
- `config.py` — налаштування.
- `db.py` — робота з базою даних.
- `encoder.py` — модуль нормалізації відео.
- `streamer.py` — модуль трансляції.
- `static/`, `templates/` — фронтенд (HTML, CSS, JS).
- `requirements.txt` — залежності.
